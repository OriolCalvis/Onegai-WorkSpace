# Biblioteca visual de enemigos v1

Atlas para consulta dentro del flujo de autoría. El orden es de izquierda a derecha y de arriba abajo:

1. Slime verde; slime venenoso; murciélago de cueva; murciélago gigante.
2. Vampiro noble; vampiro acorazado; zombi musgoso; zombi esquelético.
3. Dragón rojo joven; dragón negro anciano; arlequín enmascarado; maestro arlequín.

El catálogo asociado es `assets/objects/editor_biblioteca_enemigos.json`. Sus IDs son estables para colocarlos en niveles; los `spriteId` siguen a `-1` para no fingir que la ilustración de referencia es ya un spritesheet de juego. La siguiente fase será recortar/animar cada enemigo y asignar el frame del atlas de runtime.
