# Bibliotecas de suelo para el editor

Los biomas se pintan con tiles de suelo. No son objetos ni criaturas.
Cada atlas es una cuadrícula de 4 por 4.

## Naturaleza

Archivo: editor_terrain_nature.png

| Fila | Materiales |
| --- | --- |
| 1 | pradera, hierba seca, sendero de tierra, barro |
| 2 | hojarasca, tierra musgosa, roca, nieve |
| 3 | arena, tierra de cañón, ceniza volcánica, turba de pantano |
| 4 | agua poco profunda, río, ruina de adoquín, piedra antigua cubierta |

## Ciudades y civilizaciones

Archivo: editor_terrain_civilizations.png

| Fila | Materiales |
| --- | --- |
| 1 | adoquín limpio, adoquín gastado, plaza, mármol real |
| 2 | suelo de vivienda, suelo de taberna, mosaico de templo, suelo de biblioteca |
| 3 | pavimento antiguo, arenisca desértica, piedra enana, senda élfica |
| 4 | ciudad en ruinas, callejón embarrado, alcantarilla, patio fortificado |

Los muros, murallas, vallas y setos permanecen en la biblioteca
editor_construction_tiles.png: son elementos de borde y estructura, no
