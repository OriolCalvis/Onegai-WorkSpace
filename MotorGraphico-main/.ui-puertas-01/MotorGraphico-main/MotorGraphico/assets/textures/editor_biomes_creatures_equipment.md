# Atlas de biomas, criaturas y equipo

Atlas editorial de 4 x 4 para identificar contenido visualmente en el
creador de niveles. Es arte de previsualización: no reemplaza sprites
animados ni el balance de las fichas RPG.

| Fila | Iconos, de izquierda a derecha |
| --- | --- |
| 1 | montaña nevada, bosque de coníferas, cañón desértico, pantano |
| 2 | lobo, oso, ciervo, jabalí salvaje |
| 3 | goblin, esqueleto, bandido, araña gigante |
| 4 | espada, arco, hacha, escudo |

Uso previsto: subgrupos visuales Biomas, Fauna, Enemigos y Equipo dentro
del editor, manteniendo las fichas de datos como fuente de verdad para
estadísticas, comportamiento y botín.
