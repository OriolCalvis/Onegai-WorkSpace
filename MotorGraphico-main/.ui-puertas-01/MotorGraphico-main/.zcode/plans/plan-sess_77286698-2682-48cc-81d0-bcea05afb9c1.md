## Objetivo

Enriquecer la UI del editor de niveles (`examples/level_editor.cpp`) con paneles visuales con jerarquía, una paleta lateral siempre visible y animaciones sutiles — manteniendo el control 100% por teclado/ratón tal como está ahora.

## Decisiones confirmadas
- Paneles con jerarquía visual (fondos, títulos, bordes).
- Panel de paleta lateral con el elemento seleccionado resaltado.
- Animaciones sutiles (cursor pulsante, contador de objetos/tiles, barra de progreso al guardar).
- Reutilizar el HUD propio existente (`HudPanel`/`HudText`/`HudCommandMenu`/`HudBar`) — sin nuevos widgets en la librería.

## Estado actual del editor
- Ventana 1280×720, mapa 8×8, un solo panel de estado arriba-izquierda (520×64) con texto de herramienta + selección + atajos.
- Render del mundo: tiles, rejilla tenue en celdas vacías, objetos, resaltado del cursor (blanco 0.25 estático).
- Controles: ratón (click izq/der), 1-4 herramientas, Q/E paleta, WASD pan, F5 guardar, ESC salir.

## Diseño

### Layout propuesto (ventana 1280×720)
```
┌─────────────────────────────────────────────────────┐
│ [BARRA SUPERIOR] Herramienta + selección + celda     │  ← arriba, ancho completo
├──────────────┬──────────────────────────────────────┤
│              │                                       │
│  [PALETA     │                                       │

│   objetos    │                                       │
```

### Panel superior (barra de estado, ancho completo, ~48px)
- `HudPanel` de fondo oscuro con borde superior de color (acento según herramienta activa).
- `HudText` con: `HERRAMIENTA: PINTAR TILE  |  SEL: GID 1  |  CELDA: (3,2)` — ahora incluye la celda bajo el cursor (variable `hovered` local).
- Color de acento por herramienta: pintar=verde, borrar=rojo, objeto=amarillo, quitar=gris.

### Panel lateral (paleta, ~240px ancho, derecha o izquierda)
- `HudPanel` de fondo.
- `HudText` título: `"PALETA"` o `"TILES"` / `"OBJETOS"` según herramienta.
- **Lista de la paleta activa**: reutilizar `HudCommandMenu` con las opciones de `editor.tilePalette()` o `editor.objectPalette()` (convertidas a strings legibles: `"TILE 1"`, `"arbusto"`, etc.). El índice seleccionado se sincroniza cada frame con el del editor.
- Debajo, un `HudText` con info del elemento seleccionado (para objetos: nombre + categoría del `ObjectCatalog`; para tiles: GID + si es colisión).
- **Sincronización**: como `EditorState` no expone su índice interno, calculo el índice del `HudCommandMenu` buscando cuál coincide con `editor.selectedTileGid()`/`selectedObjectId()` y hago `setSelectedIndex`.

### Panel inferior (barra de atajos + stats, ~56px)
- `HudPanel` con borde inferior de acento.
- `HudText`: `"1-4 HERRAMIENTA  Q/E PALETA  WASD PAN  F5 GUARDAR  ESC SALIR"` + `"TILES: 12  OBJETOS: 3"` (contadores en tiempo real desde `editor`).

### Animaciones (estado temporal en el bucle)
Necesito un struct de estado de animación local al `main` (los widgets HUD no tienen `update()`):
- **Cursor pulsante**: el resaltado del cursor alterna su alpha entre 0.20 y 0.45 con una onda senoidal (`sin(time * 4)`). Mucho más fácil de localizar la celda activa.
- **Flash de "guardado"**: al pulsar F5, un overlay verde semitransparente breve (~0.4s) cubre la pantalla + texto `"¡GUARDADO!"` que se desvanece. Feedback claro de que F5 funcionó.
- **Borde de herramienta animado**: la barra superior cambia de color de acento al cambiar de herramienta con una transición suave (lerp del color durante ~0.15s).

### Bordes de paneles
Como `HudPanel` es un quad sólido (sin borde), dibujo bordes manualmente con `SpriteBatch`: 4 quads finos (top/bottom/left/right) de 2px en color de acento alrededor de cada panel, dentro de la misma tanda HUD. Helper local `drawBorder(batch, x, y, w, h, thickness, color)`.

### Paleta de colores del editor (constantes locales en level_editor.cpp)
Defino un `namespace EditorColors` con: `kNavy{0.10,0.10,0.14}`, `kPanelBg{0.05,0.05,0.08,0.85}`, `kAccentPaint{0.20,0.70,0.30}`, `kAccentErase{0.80,0.20,0.20}`, `kAccentObject{0.95,0.85,0.20}`, `kAccentRemove{0.55,0.55,0.60}`, `kHighlight{1.0,0.9,0.2}`, `kText{0.85,0.85,0.85}`, `kGrid{1,1,1,0.06}`.

3. **Inspección visual**: PPM/sondas confirman que los paneles se dibujan (fondos + bordes + texto legible), la paleta muestra la selección resaltada, y el cursor pulsa.
4. **Funcionalidad intacta**: pintar/borrar/colocar/guardar siguen funcionando (F5 sigue generando el TMX/JSON).
5. **clang-format** pasa en level_editor.cpp.

## Qué NO haré
- No añadir widgets nuevos a la librería HUD (todo con los existentes).
- No tocar `EditorState` (sigue siendo GL-free; la UI vive en el demo).
- No ImGui (sigue sin poder vendorizarse).
- No commits (working tree).
