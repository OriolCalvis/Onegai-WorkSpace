Autoridad visual preservada desde la referencia subida

fidelidad shell completa tono editor técnico sobrio

Esta comparativa no deriva desde una landing ni desde un dashboard SaaS. Se apoya en la referencia subida para mantener el carácter de editor de motor: barras rectas, monoespaciada, retícula isométrica, paleta contenida y decisiones visibles de implementación.

Shell
  • Topbar extendida con marca, nombre de nivel, tabs, estado UNSAVED y acción guardar.
  • Dock izquierdo como bloque de trabajo, no como navegación de producto.
  • Status bar inferior global con atajos persistentes.
Canvas
  • Retícula isométrica central con chips de cell, gid, zoom e información ISO.
  • Etiquetas flotantes y marcadores de objetos sin depender de imágenes externas.
  • Consola inferior integrada dentro del área central como en la referencia.
Inspector
  • Campos técnicos en columna derecha con warning real y binding C++ visible.
  • Capa de anotaciones incluida para explicar autoridad visual y fidelidad.
  • Texto en español manteniendo MAP, OBJECTS, LIBRARY, UNSAVED y SAVE por fidelidad.
