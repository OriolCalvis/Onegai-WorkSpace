⚙️ Stack IA Onegai

Gestiona Ollama + AuthorAgent simultáneamente mediante los scripts de .onegai_ai_config/scripts/.

(pulsa "Comprobar estado detallado")

Scripts disponibles en .onegai_ai_config/scripts/

  • start-agents.sh — variables de paralelismo + healthcheck Ollama + warmup + arranca AuthorAgent
  • stop-agents.sh — descarga modelos keep_alive=0 + para AuthorAgent
  • status-agents.sh — dashboard con colores: health, modelos, RAM/VRAM, logs, ollama ps
  • switch-authoragent-profile.sh writer|critic|status — cambia perfil en config JSON AuthorAgent
  • tests-rapidos.py — batería 10 tests (~3 min): identidad, outline, crítico, paralelo, alternancia
  • build-models.sh — reconstruye ollama create onegai/story-writer y onegai/author-critic

Encargos

Se ejecutan uno tras otro y se guardan en la carpeta salidas.
